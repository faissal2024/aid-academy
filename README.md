# Academy Contact Organizer

Arabic RTL, local-first contact-list organizer. It imports XLSX, XLS, CSV and TXT files, normalizes Moroccan mobile numbers, retains the final occurrence of each number, groups contacts by level, and exports final records—without uploading contact data.

## Run

```bash
npm install
npm run dev
```

Place the official Academy logo at `public/assets/academy-logo.png` when it becomes available.
